# APIs and Extensions

Integrate Faction with the rest of your tooling: a REST API for everything in the product, and an App Store extension API for hooking your own code into assessment, vulnerability and report events.

<div class="grid cards" markdown>

- **[REST API](REST%20API.md)** — create and read assessments, vulnerabilities and more from your own scripts and tools.
- **[App Store Extension API](App%20Store%20Extension%20API.md)** — write a Java extension that reacts to Faction events and install it from the App Store.
- **[JIRA App Integration Example](JIRA%20App%20Integration%20Example.md)** — a worked example that pushes findings into JIRA through an extension.
