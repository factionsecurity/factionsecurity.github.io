# AI Integrations

Faction can use a large language model to write executive summaries and report sections, review checklists, and answer questions about assessments through MCP. Configure a provider first, then use the assistants.

<div class="grid cards" markdown>

- **[AI Configuration (Enterprise)](AI%20Configuration%20(Enterprise)/index.md)** — connect Anthropic, Azure AI Foundry, OpenAI or any OpenAI-compatible endpoint.
- **[AI Report Assistant (Enterprise)](AI%20Report%20Assistant%20(Enterprise).md)** — generate executive summaries and expand report sections from a prompt.
- **[AI Checklist Review (Enterprise)](AI%20Checklist%20Review%20(Enterprise).md)** — automatic review of incomplete checklist items against the findings.
- **[Faction MCP Server](Faction%20MCP%20Server.md)** — expose assessments, vulnerabilities, retests and audit logs to any MCP-compatible AI client.

</div>
